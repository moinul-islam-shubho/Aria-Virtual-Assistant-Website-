A CSE4200 web programming project

Ask once. Aria gets it done.

Aria is a browser-based virtual assistant that turns plain-language requests into reminders, quick answers, and next steps — no install, no account, no waiting.

Built to actually help, not just chat

Three things Aria focuses on doing well, instead of trying to do everything.

💬

Understands plain language

Type a request the way you'd say it to a person. Aria matches intent instantly, without menus or commands to memorize.

🧠

Follows the conversation

Follow-up questions carry context from earlier in the chat, so you're never repeating yourself.

⚡

Runs anywhere, instantly

Pure front-end — HTML, CSS, and JavaScript. Opens in a tab and responds with zero load time.

How a request becomes an answer

Every message follows the same three-part path.

01

Ask

Type what you need in your own words — a reminder, a question, a quick task.

02

Understand

Aria matches your message to an intent and pulls out the details that matter.

03

Respond

You get an instant reply, right in the same window — no page reload.
